# hopo 2.6.4: no more freezes, delete a transfer, livelier send ring

Reported: the app gets stuck and can't be used; the admin wants to delete single transfers from the list; the Ctrl+Shift+S ring is static.

Freezes (found in the code: work that made the window wait):
- [ ] The phone page's web server starts in the background. Starting sharing, saving Settings or reconnecting after a network change no longer freezes the window while it starts (up to 3 more seconds when it restarts). Open in browser waits for it.
- [ ] The 10-second network check reads the network adapters in the background instead of on the window.
- [ ] Transfers and History no longer check each receive folder on disk while drawing (an unplugged or network drive froze the window); History redraws only when its list changes; both pages show the newest 50.
- [ ] Reading the Explorer selection for the ring runs in the background with a 3-second limit, so a busy Explorer cannot freeze hopo.

Delete a transfer (hopo Admin):
- [ ] A Delete button on each finished transfer in Transfers and History, after a confirmation. It removes only the record; received files stay on disk. Active transfers cannot be deleted. Test included.

Send ring:
- [ ] The ring opens with a short pop and fade; the devices appear one after another in their places (they do not move around); a slowly turning ring in the Home ring colours; each device has its own colour, and the one under the pointer or keyboard glows and grows a little. No motion when Windows animations are off.

Release:
- [ ] Version 2.6.4, both MSIs verified and copied to dist\, keeping the last two Windows versions (2.6.3 and 2.6.4).
